# GitHub Week 6 Assignment

This project contains a Java implementation of the Week 6 gym-membership assignment described in the problem sheet.

## Structure
- `GymMember.java` – base class with validation, batch signup, fee history, referral code checks, and weekly check-in processing
- `PremiumMember.java` – premium subclass with trainer and late-fee discount logic
- `EliteMember.java` – multilevel member type
- `GroupClassMember.java` – separate membership branch
- `Main.java` – demonstration of the required examples

## Run
```bash
javac *.java
java Main
```
